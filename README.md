### About

I build **working AI products, not notebooks** — small, honest stacks that put a usable interface in front of a real problem.

My focus is career-tech: a resume gets parsed, scored against ATS rules, turned into interview practice, mapped to a skill gap, and exported as a report someone can actually keep.
